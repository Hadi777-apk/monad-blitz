# Monad Blitz

Monad Blitz 上海参赛项目的开源仓库。当前处于构思与准备阶段，具体产品方向待定。

## 项目目标

在 Monad 测试网上构建一个可公开访问、可现场演示的原创应用原型。

## 当前状态

- 已建立仓库并采用 MIT 开源许可证。
- 暂未编写应用、智能合约或部署脚本。
- 活动前用于调研和方案规划；项目开发在活动正式时间内开始。
