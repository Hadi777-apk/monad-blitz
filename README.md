# Blitz Mine · 千枚矿场

一个拟部署在 Monad 测试网上的多人挖矿游戏：玩家通过浏览器计算挑战，或选择实验性的 AI 编程用量模式，争夺固定总量的 1000 枚游戏代币。

**当前阶段：方案 v0.1，供队友讨论；仓库只有文档，尚未编写、部署或验证游戏代码。**

## 一分钟了解

- 游戏代币暂名 `BLITZ`，总量固定为 1000 枚；不是 BTC，也不是 Monad 官方 MON。
- 800 枚用于可验证计算挑战，200 枚用于实验性编程用量模式；两个奖池独立计分。
- 标准轮次为 5 分钟，每个奖池各有 100 个有效分配轮次，每次分别分配 8 枚、2 枚。
- 同一奖池、同一轮内，按有效积分占比分配；空轮不消耗额度。
- 本地 AI tokens 可以被伪造，实验模式明确采用受信任裁判，不宣称无信任验证。
- 不出售挖矿加成，不提供充值、交易市场或收益承诺；MON 仅用于测试网交易手续费。

以上均为拟议规则，不代表已有实现。参数在正式部署前可以讨论修改，启动后按该实例冻结的规则执行。
