# 安全与信任模型 v0.5

日期：2026-10-17。仅设计要求，尚未实现、测试、部署或审计。

## 1. 信任与权限

A 的答案由合约验证，没有后台分数表。开/关轮、领奖、完成交易与适用的超时退出均不需要项目管理员批准。用户自行保管钱包；网站、榜单和事件读取可以替换。

Mining 与 Escrow 不互相调用、不共享资金；它们仍需正常调用代币和 NFT。无后续增发、任意提款、升级旧核心、人工裁判、B 启用/迁移或后台冻结既有权益的权限。

不可升级减少单方改规则的能力，也可能导致漏洞无法就地修复。测试代币与测试 NFT 的正确性、底层链执行、RPC 可达及用户钥匙保管仍是依赖，不能声称完全无风险。

## 2. 资产和状态不变量

| 编号 | 必须成立 |
| --- | --- |
| G1 | BLITZ 初始化总量 1000；A 累计支付<=800，B 固定锁定 200，无救援或迁移路径 |
| G2 | R_A+E_A+U_A+C_A+L_B=1000，E_A 为当前轮预留，L_B=200 |
| G3 | 每个有效答案 1 分，贡献连续不重叠；关闭后区间奖励求和精确等于该非空轮预算 |
| G4 | 一次只开一轮；空轮不消耗名额，第 100 个非空轮后不能重开增加额度 |
| T1 | 每单累计实付/退款 + 已记可领取 + 仍锁定 = 实际有效入金 |
| T2 | 同一订单 Complete 与 Exit 不可能都成功，退出和资金记账只执行一次 |
| T3 | NFT 原子交付失败不得遗留完成状态或卖家 2P 的余额 |
| T4 | NFT 拒收不能撤销先前退款记账；取回权只归原卖家及其具体授权，不能重复使用 |
| T5 | 同一 NFT 不能被两个订单或两次返还支配；资金与 NFT 返还记录分开 |
| S1 | 签名/答案绑定链、实例、相关对象和 nonce；订单使用/取消、恢复授权重放状态可查 |
| S2 | 订单终态不可倒退，但余额提现和 NFT 取回可继续 |

协议负债账与直接转入的意外资产不同，意外转账不增加可分配预算，不自动产生第三方返还权。

## 3. 三处必须进入实现验收的边界

授权取回：原卖家可选非零且非 Escrow 的接收地址；其他调用者需要专门绑定订单/资产/动作/接收地址/链/合约/版本/nonce/有效期的授权。失败不消费取回权、不影响付款退款，成功不可重放。

时间与状态：创建 now<F<D，入金 now<F，完成要求 fullyFunded 且 now<D；入金超时要求未完整入金且 now>=F；交付超时要求已完整入金但未交付且 now>=D。终态不能再完成、入金或制造退款。

合约隔离：不把“不互相调用”误写成没有外部调用。支付币主动提现；NFT 安全转移仍可能触发接收回调，要处理检查-状态-调用顺序、重入和交易回滚。

## 4. 主要威胁与防护

| 威胁 | 设计要求 |
| --- | --- |
| 伪造算力/后台积分 | 验算哈希与去重，记录归属钱包；不信速度或本地日志 |
| 复制答案、跨链重放 | 绑定链、实例、轮次、种子、钱包、nonce；不能换收益地址 |
| 订单签名重放/取消后复活 | 完整 EIP-712 域与条款，单独记录已用/已取消状态；明确双角色与 nonce 范围 |
| NFT 返还授权被偷用 | 具体动作与接收人绑定、有效期、一次性 nonce，仅原卖家可签发 |
| NFT 未真实托管/重复归属 | 实际接收、订单归属与预留，不能仅检查批准或合约总持有 |
| 恶意资产/接收回调 | 首版限定测试资产，金额核对、重入保护、失败原子回滚与独立退款 |
| 取回失败阻塞退款 | Exit 不转 NFT；之后单独取回，退款与返还权独立 |
| 链上共享热点/存储增长 | 操作有界、领取分批、实测总分写入热点；不承诺无限吞吐 |
| 私钥/代码/会话泄露 | 不收用户密钥与原始聊天，不把本地钱包或 Mojo 凭据上传仓库 |

难度 16 位与区块种子都不是公平真人证明；设备优势、交易排序、费用和链拥堵仍影响游戏。B 不接本地自报奖励，不宣称哈希或多签可证明真实 AI 用量。

## 5. 去中心化可用性

贡献、预算、签名状态、订单、余额和返还权以链上为准。可选事件读取不应成为行使权利的前置服务；备用客户端/交互说明属于未来交付。

任何人可执行适用的关闭和超时动作，收款归属固定。自动执行需要有人发交易，时间流逝本身不会运行合约。用户仍需可用网络/RPC、手续费和对应钥匙；不作“任何故障都一定能取回”的承诺。

敏感证据与链外裁决尚不属于当前实现范围。未来引入时另做信任、证据可用性和失联分配设计，不能把当前同链原子交易能力宣传成真实皮肤或实物已接入。

## 6. 后续必须执行的检查

1. 分币：8 个最小单位/8 枚分别分三份、随机区间、空轮、预算预留与返还、第 100 轮、分批/重复领奖。
2. 截止：恰好 F/D 时动作被拒绝或退出允许；F 后已完整入金仍可在 D 前成交；终态不能再退/再成交。
3. 资产：单方超时、完整入金未交付、NFT 拒收、失败完成回滚、重复 NFT、错 tokenId、重复出资。
4. 恢复：退款资金可独立取出；原卖家换有效接收地址可取回；他人不能换接收人，授权过期/重放失败。
5. 权限：不能增发、动 B、提走 Mining 金库、挪别单资金或修改既有条款；所有关键签名域齐全。
6. 可用性：关闭项目服务后独立客户端继续开关轮、领奖、退出和取回；查询滞后不冒充成功。
7. 成本：提交/关闭/领取/交付/退款的 gas、确认延迟、单轮共享总分热点和存储增长。
8. 网页：钱包签名内容可读，错误网络/失败状态清楚；入口与版本不缓存、资源哈希、旧标签页自动更新及失效分块恢复。

上述检查均为未来要求，本轮只有文档一致性与算例核对。代码审查必须沿用用户指定的 Hadi777-apk/open-code-review 委托流程；文档检查不是代码审查或审计。
